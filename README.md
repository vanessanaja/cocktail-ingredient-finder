# Drink Ingredients App

A JavaScript application built for a mobile bartending business.

Users can enter preferred ingredients and receive a list of matching drink recipes.

## Project Background

This project was created to solve a real business need for a friend who wanted customers to be able to search for drinks based on ingredients they already liked.

A suitable free API was not available at the time, so I sourced a cocktail dataset and imported the data into MongoDB.

## Data Source

Cocktail ingredient data was sourced from Kaggle:

https://www.kaggle.com/ai-first/cocktail-ingredients
